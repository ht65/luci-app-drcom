# luci-app-drcom

给 **ImmortalWrt 25.12 及以后**用的 Dr.COM（城市热点）校园网网页认证插件，带 LuCI 网页界面。

装好后，路由器会代替电脑完成校园网登录；接在路由器后面的手机、电脑共享同一条已认证的连接，不用每台设备各自登录。

本项目基于 **重庆财经职业学院** 校园网实测开发，本校同学用默认配置即可；其他学校需要改一下「认证门户」地址。

> **只支持 ImmortalWrt 25.12+（apk 包管理）。**
> ImmortalWrt 24.10 及更早、以及 OpenWrt 其他版本不支持。

## 安装前须知（第一次安装必看）

安装包已经签名。ImmortalWrt 默认只认识官方签名，所以**第一次安装时，需要把本项目的公钥放到路由器里**（只需一次）。放好之后：

- 以后每个新版本都可以直接安装、直接升级，**不用再加公钥**；
- 也可以在 LuCI 的「软件包 → 上传包」里直接选 apk 安装。

公钥就是一个公开的小文件，**不是密码**，可以放心分享。

## 安装

### 第一步：添加公钥（只需做一次）

两种方法任选一种。

**方法 A：路由器能访问 GitHub**

用 SSH 登录路由器，执行：

```sh
mkdir -p /etc/apk/keys
wget -O /etc/apk/keys/drcom.pem \
  https://github.com/ht65/luci-app-drcom/releases/latest/download/drcom.pem
chmod 644 /etc/apk/keys/drcom.pem

# 让固件升级后也保留这把公钥
echo '/etc/apk/keys/drcom.pem' >> /etc/sysupgrade.conf
```

**方法 B：电脑下载，再传到路由器（校园网访问 GitHub 慢时用这个）**

在电脑上（Windows PowerShell）：

```powershell
curl.exe -L -o drcom.pem `
  https://github.com/ht65/luci-app-drcom/releases/latest/download/drcom.pem

scp -O .\drcom.pem root@192.168.1.1:/tmp/
```

然后 SSH 登录路由器：

```sh
mkdir -p /etc/apk/keys
cp /tmp/drcom.pem /etc/apk/keys/drcom.pem
chmod 644 /etc/apk/keys/drcom.pem
rm -f /tmp/drcom.pem
echo '/etc/apk/keys/drcom.pem' >> /etc/sysupgrade.conf
```

> `scp` 必须加 `-O`，否则会报错；这是 ImmortalWrt 的 SSH 不支持 SFTP 导致的。

### 第二步：安装插件

**推荐：apk 安装**

1. 打开 [Releases](https://github.com/ht65/luci-app-drcom/releases)，下载最新的 `luci-app-drcom-<版本>-r1.apk`（当前为 `luci-app-drcom-1.0.15-r1.apk`）。
2. 传到路由器：

   ```powershell
   scp -O .\luci-app-drcom-1.0.15-r1.apk root@192.168.1.1:/tmp/
   ```

3. SSH 登录路由器安装：

   ```sh
   apk add /tmp/luci-app-drcom-1.0.15-r1.apk
   rm -f /tmp/luci-app-drcom-1.0.15-r1.apk
   ```

**也可以用 LuCI 安装**：登录 LuCI → **系统 → 软件 → 上传包** → 选择下载好的 apk → 安装。

### 第三步：打开插件填写账号

登录 LuCI → **服务 → Dr.COM 认证**：

1. 填写校园网账号、密码；
2. 需要的话选择运营商（校园移动/校园用户留空，电信选 `@dx`，联通选 `@lt`）；
3. 点「保存并应用」。

账号密码只保存在路由器本地，不会上传到别处。保存后最多等一轮检测（默认 60 秒）就会自动认证；想立刻生效，点页面上的「重启服务」。

### 以后升级

下载新版本的 apk，再执行一次 `apk add`，或者用 LuCI「上传包」安装即可。**公钥不需要重新加**，账号密码也不会丢。

### 如果暂时不想加公钥

也可以先用 `--allow-untrusted` 应急安装：

```sh
apk add --allow-untrusted /tmp/luci-app-drcom-1.0.15-r1.apk
```

但这样在 LuCI 网页上传安装仍然会失败，所以还是建议按第一步加上公钥。

## 怎么用

### 首页状态卡片

能看到当前是否已认证、上行接口、本机 IP、认证账号、认证服务器、最近一次错误、状态多久前更新。

### 手动操作

- **上线（拉起上行）**：重新连接上行并解除「已下线」状态。
- **立即重新认证**：只重新登录一次，不重拨接口；已在线时不会重复登录。
- **下线路由器**：断开本机上行并暂停自动认证。只影响这台路由器，不影响同账号的手机；重启路由器后仍保持下线，需要点「上线」恢复。
- **重启服务**：让刚改的设置立刻生效。

### 当前连接设备

列出接入路由器的设备：名称、IP、MAC、有线 / WiFi。

- **断开**：立即切断该设备已有的连接，并持续阻止它上网，直到你点「解除」或关闭插件总开关。
- **解除**：恢复该设备上网。
- 断开的设备会自动从列表消失；被你断开的设备会保留在列表里，方便随时解除。

> 请不要对自己正在使用的设备点「断开」，否则你自己也会短暂断网。

### 实时日志

分「自动认证」和「手动操作」两类，可以切换查看；排查问题时很有用。

### 插件总开关

在页面顶部。停用后插件完全停止工作（不探测、不认证、也不动上行接口），适合临时改用 USB 网卡等其他上网方式。

## 常用设置

| 设置 | 说明 |
| --- | --- |
| 账号 / 密码 | 校园网账号密码 |
| 运营商 | 校园移动/校园用户留空，电信 `@dx`，联通 `@lt` |
| 终端类型 | `PC` 占用电脑槽位（默认），`手机` 占用移动终端槽位 |
| 上行接口 | `auto` 自动在无线中继 `wwan` 和有线上行 `wan` 里选已连上的那个 |
| 认证门户域名 / 认证服务器 IP / 端口 | 换学校时改这里；本校默认值已填好 |
| 在线检测间隔 | 单位秒，默认 60。越大越省流量，越小掉线恢复越快 |
| 失败重试间隔 / 最大重试间隔 | 认证失败后的重试节奏，一般保持默认 |
| 连续失败上限 | 连续失败多少次后暂停自动重试，默认 5，避免账号被风控 |

一般只需要填账号密码，其他保持默认。

## 常见问题

**安装时提示 `UNTRUSTED signature`**

说明路由器还没加本项目的公钥。回到「第一步：添加公钥」，确认公钥文件在 `/etc/apk/keys/drcom.pem`。

**加过公钥，但固件升级后又提示签名错误**

`/etc/apk/keys/` 里的文件在固件升级时可能丢失。重新执行一次添加公钥，并确认已把路径写入 `/etc/sysupgrade.conf`。

**一直显示「未认证」**

按顺序检查：

1. 账号、密码是否正确，运营商是否选对；
2. 认证门户域名 / 服务器 IP 是否是本校的（换学校必须改）；
3. 页面「最近错误」和实时日志里写了什么。

改好后点「立即重新认证」，或等下一轮自动重试。

**提示「连续认证失败，已暂停自动重试」**

这是为了避免账号被风控。检查账号密码/运营商后，点「立即重新认证」即可恢复；如果网络自己恢复了，也会自动解除暂停。

**设备列表是空的 / 不能断开设备**

设备的识别和断网依赖系统的 `conntrack`、`iw` 和 nft 的 bridge 支持。缺这些时，认证上网仍然正常，只是设备管理功能会受限；界面和日志会给出提示。

**「下线路由器」之后上不了网**

这是正常的：下线会断开上行。回到页面点「上线」即可恢复。

**路由器重启后还是「已下线」**

下线状态会被记住，点「上线」恢复。

## 卸载

用 apk 安装的：

```sh
apk del luci-app-drcom        # 删除插件，保留账号密码配置
rm -f /etc/config/drcom       # 想连账号配置一起删，再加这句
```

卸载时会一并清理设备阻断规则和运行状态，不会留下「设备一直被断网」的残留。

## 命令行（排错用，可跳过）

```sh
/usr/sbin/drcom-portal status    # 查看当前状态、最近错误和连通性
/usr/sbin/drcom-portal login     # 立即重新认证
/usr/sbin/drcom-portal online    # 上线
/usr/sbin/drcom-portal offline   # 下线
logread -e drcom | tail -n 30    # 查看日志
```
